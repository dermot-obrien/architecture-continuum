# Capability Standards

This folder contains normative standards only.

## Included

- `standard-capability-document.md`
- `standard-capability-diagram.md`
- `standard-definition-ladder.md`, with its machine-readable stages in `definition-ladder.csv`

## Excluded

Concrete capability instances (`CAP-*`), capability registries, and capability diagrams are not stored here. They belong in:

- Workspace canonical content (`capabilities/`), or
- Framework seed content (`foundation/capabilities/`).
